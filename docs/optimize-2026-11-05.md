## Changes

### Trail work
- I kept the in-progress trail work as you left it and pushed it: Arena previews load only when they scroll near the reader, linked Arena blocks that aren't loaded yet show a recovery notice, and the unused `embed` metadata is gone. The smoke tests you wrote for it pass.

### Bugs fixed
- **Bluesky search was broken when `.env` is missing.** `VITE_WORKER_URL` was undefined, so the reader fetched `undefined?url=…` and showed a JSON parse error instead of searching. It now falls back to `https://bsky-search.henry.ink`, the same default the smoke test and `.env.production.example` use. This was also the cause of the failing smoke test.
- **Extension build was broken.** WXT always maps `@` to `srcDir`, which overrode the repo-root alias, so every shared `@/src/...` import failed. `srcDir` is now the repo root, with entrypoints and public kept in `extension/`.
- **Mixed React signals runtime.** Ten components imported `useSignal` from `@preact/signals-react`, which is the React integration, inside a Preact app. They now all use `@preact/signals`, and the dependency is removed.
- **Hook order in `FirstTimePopup`.** It returned early before calling `useSignal`/`useComputed`. It is now a version check in front of a separate body component.
- **Arena match text drifted off the matched words.** Content was trimmed and entity-decoded before matching, but positions were read back from the original string. Any leading whitespace shifted `matchedText`, which is what the reader navigates by. Content is now only lowercased, which keeps positions aligned. Added a regression test.
- **API errors arrived without CORS headers.** Route handlers were returned without `await` inside `try`, so a rejected handler skipped the catch. Bun then answered with its own 500 and no CORS headers, and the browser saw an opaque network error.
- **The IndexedDB query cache never shrank.** TanStack's experimental persister only drops an expired entry when that same query is read again. The storage now has `entries()`, and `persisterGc()` runs once per session when the browser is idle.

### Bundle and load time
- Post embeds now switch on `$type` instead of validating with `is(schema, …)`. This takes all runtime code from `@atcute/bluesky` and `@atcute/lexicons` out of the bundle, and embeds are no longer deep-validated on every render.
- A small `lazyComponent` helper (`src/lib/lazy-component.tsx`) uses a signal instead of Suspense. It is used for three things most readers never open:
  - the Bluesky composer (`QuoteComposer`)
  - the Arena block viewer
  - the welcome/changelog steps
- `@atcute/oauth-browser-client` is now a dynamic import. Signed-out readers never download it; it loads for a stored DID, an OAuth callback, sign-in or sign-out.

### Dead code and tooling
- Removed the unused `marked`, `vite-plugin-dts` and `@preact/signals-react` dependencies.
- Biome now follows `.gitignore`, so it no longer lints build output. Its version is pinned as a dev dependency, and `bun run lint` works.
- `noControlCharactersInRegex` is turned off because the sanitizers match control characters on purpose.
- Fixed the unused bindings that biome reported.

## Follow-ups
- **Biome a11y:** 26 `noStaticElementInteractions` and 17 `useSemanticElements`. These are mostly click handlers on `div`s in the post and Arena components and need a design pass, not mechanical fixes.
- **The API isn't load-tested.** There is no `channels.db` in the container. The enhance path already skips matcher rebuilds when the channel data hasn't changed, and it has an LRU. Consider a request-body size cap on `/api/arena/enhance`, since `content` is unbounded today.
- **Arena match positions with unusual Unicode:** `toLowerCase()` can change the length of a few characters, such as `İ`. If that matters, match on a case-folded copy and keep an offset map back to the original text.
- **Remaining main-chunk weight** is mostly core: TanStack Query (~76 kB source), DOMPurify (~61 kB), Preact. DOMPurify could be loaded with the first sanitized render if the reader can show its loading state for one more round trip.
- **Not tested end to end:** restoring a signed-in session with the lazy OAuth module. It needs a real Bluesky OAuth flow; I only reviewed the code. The signed-out path is covered by the smoke tests.
- `src/components/experimental/*` is only used by `demo/routes/ThreadTest.tsx`. It's a candidate for deletion if that demo is retired.
